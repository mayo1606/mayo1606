# Character model assets

Place the six game-ready models in this folder using these exact names:

- `goku_ssj3.glb`
- `piccolo.glb`
- `vegeta.glb`
- `frieza.glb`
- `cell.glb`
- `majin_buu.glb`

The game now automatically loads these files with GLTFLoader, applies the project's toon material, normalizes character height, preserves the existing aura/shadow/combat logic, and falls back to the procedural character if an asset is absent.

## Selected source models

- Goku SSJ3 — King_45, “Goku Super Saiyan 3 | Dragon Ball Sparking Zero”, Sketchfab, CC BY
- Piccolo — 20062020year, “DBFZ DBSH PICCOLO”, Sketchfab, CC BY
- Vegeta — Muhammad, “Vegeta”, Sketchfab, CC BY; described as FBX, texture mapped, rigged and animated
- Frieza — BenAissa_Karim, “Frieza”, Sketchfab, CC BY
- Cell — Chechorams16, “Cell Perfect - Dragon Ball Z”, Sketchfab, CC BY
- Majin Buu — thunders14, “majin buu”, Sketchfab, CC BY

For private use, keep source/author attribution with the assets.
